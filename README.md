# 🌅 Sunrise Public School Website

A beautiful, modern, and fully responsive website for Sunrise Public School built with Next.js, React, and Tailwind CSS.

## ✨ Features

### 🎨 **Frontend Features**
- **Beautiful Design**: Modern, clean, and professional UI
- **Fully Responsive**: Works perfectly on all devices
- **Smooth Animations**: Framer Motion animations throughout
- **Interactive Elements**: Hover effects, transitions, and micro-interactions
- **Fast Loading**: Optimized for performance

### 📱 **Pages & Sections**
- **Homepage**: Hero section, stats, features, testimonials, CTA
- **About**: School history, mission, vision, values
- **Academics**: Programs for all grades (Primary, Middle, High School)
- **Admissions**: Online application form with validation
- **News & Events**: Latest school news and upcoming events
- **Gallery**: Photo gallery with categories
- **Contact**: Contact information and form

### 🔐 **Admin Portal**
- **Dashboard**: Overview of applications and statistics
- **Admissions Management**: View and manage student applications
- **News Management**: Create and edit news articles
- **Gallery Management**: Upload and manage photos
- **User Authentication**: Secure admin login system

## 📦 **Installation & Setup**

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/SRSproject.git
   cd SRSproject
   ```

2. **Install dependencies**
   ```bash
   cd client
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   ```
   http://localhost:3000
   ```

### Production Build

1. **Build for production**
   ```bash
   cd client
   npm run build
   ```

2. **Export static files**
   ```bash
   npm run export
   ```

## 🌐 **Deployment**

### GitHub Pages (Automatic)

1. **Enable GitHub Pages** in repository settings
2. **Set source** to "GitHub Actions"
3. **Push to main branch** - automatic deployment will start

### Manual Deployment

1. **Build the project**
   ```bash
   cd client
   npm run build
   ```

2. **Upload the `out` folder** to your hosting provider
